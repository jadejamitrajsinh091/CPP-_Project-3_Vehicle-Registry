# C-_Project-3_Vehicle-Registry

# 🚗 C++ Program – Vehicle Registry System

---

This project is a complete **Vehicle Registry Management System** written in C++ using Object-Oriented Programming concepts.

The system demonstrates advanced OOP features like:

- Inheritance
- Multilevel Inheritance
- Hierarchical Inheritance
- Hybrid Inheritance
- Virtual Functions
- Runtime Polymorphism
- Encapsulation
- Dynamic Memory Allocation
- STL Vector
